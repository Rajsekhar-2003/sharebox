
# ShareBox – Flask Text & File Sharing App

ShareBox is a fast, secure, SEO-optimized web application built with Python Flask for sharing text notes and uploading/downloading files instantly.

## Features

- ✅ Text sharing (pastebin style)
- ✅ File uploads & downloads
- ✅ Bootstrap 5 responsive UI
- ✅ SEO-friendly meta tags
- ✅ Share links with QR code
- ✅ Expiring files & texts (auto-delete)
- ✅ SQLite storage (no external DB required)

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.
